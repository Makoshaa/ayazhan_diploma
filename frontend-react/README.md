# PII Detection App - React + Vite + Tailwind

Современное приложение для обнаружения и обезличивания персональных данных (PII).

## Технологии

- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev server
- **Tailwind CSS** - стилизация
- **Framer Motion** - анимации
- **Lucide React** - иконки

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск dev сервера

```bash
npm run dev
```

Приложение откроется на `http://localhost:8080`

### 3. Сборка для продакшена

```bash
npm run build
```

## Требования

Перед запуском убедитесь, что запущены backend сервисы:

- **Analyzer** на порту 3000
- **Anonymizer** на порту 3001

## Структура проекта

```
src/
├── components/          # React компоненты
│   ├── Header.tsx      # Шапка приложения
│   ├── Settings.tsx    # Панель настроек
│   ├── ControlPanel.tsx # Панель управления
│   ├── TextInput.tsx   # Поле ввода текста
│   ├── ResultPanel.tsx # Панель результатов
│   ├── PIIList.tsx     # Список найденных PII
│   └── Notification.tsx # Уведомления
├── api.ts              # API функции
├── types.ts            # TypeScript типы
├── App.tsx             # Главный компонент
├── main.tsx            # Точка входа
└── index.css           # Глобальные стили
```

## Возможности

✅ Анализ текста на наличие PII
✅ Обезличивание найденных данных
✅ Подсветка PII в исходном тексте
✅ Поддержка английского и русского языков
✅ Копирование результата в буфер обмена
✅ Красивые анимации
✅ Адаптивный дизайн
✅ TypeScript для безопасности типов

## Разработка

- Hot Module Replacement (HMR) для быстрой разработки
- TypeScript для проверки типов
- Tailwind CSS для быстрой стилизации
- ESLint для проверки кода (опционально)
