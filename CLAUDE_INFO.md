## 🎯 Как Использовать

### Включение Claude AI:

1. Запустите приложение
2. Нажмите **Settings (⚙️)** в правом верхнем углу
3. Найдите **"🤖 AI Enhancement"**
4. Включите **"Enable Claude AI Validation"**
5. Готово! ✨

### Тестирование:

Введите текст с PII:
```
Меня зовут Иван Петров, мой ИИН 900101300123, 
телефон +7 (701) 234-56-78, email ivan@example.kz
```

Нажмите **Analyze** и увидите:
- ✅ Presidio найдет базовые PII
- ✅ Claude найдет ИИН, БИН и другие казахстанские данные
- ✅ Claude устранит ложные срабатывания

## 🎯 Специализация для Казахстана

Claude настроен для детекции:

### 1. ИИН (Individual Identification Number)
- **Формат:** 12 цифр (YYMMDDCXXXXX)
- **Валидация:** проверка даты рождения
- **Пример:** 900101300123

### 2. БИН (Business Identification Number)
- **Формат:** 12 цифр для организаций
- **Пример:** 123456789012

### 3. Казахстанские телефоны
- **Формат:** +7 7XX XXX XX XX
- **Операторы:** 700-778 (Kcell, Activ, Beeline, Tele2)
- **Отличие от РФ:** начинается с 7XX (не 9XX)

### 4. Казахские имена
- **Окончания:** -ov/-ova, -ev/-eva, -uly/-kyzy
- **Формат:** Фамилия Имя Отчество

### 5. Адреса
- **Города:** Астана, Алматы, Шымкент, Караганда
- **Форматы:** ул./көше, пр./даңғылы, мкр./шағын аудан

## ❓ FAQ

### Q: Нужен ли мне свой API ключ?
**A:** Нет, встроенный ключ работает. Свой ключ нужен только при большой нагрузке.

### Q: Сколько стоит использование Claude?
**A:** Встроенный ключ - бесплатно для вас. Если используете свой - $5 бесплатно при регистрации.

### Q: Можно ли использовать без Claude?
**A:** Да, просто не включайте его в Settings. Presidio работает отлично сам по себе.

### Q: Claude медленнее?
**A:** Да, на 2-3 секунды. Но точность выше на 25%!

### Q: Работает ли офлайн?
**A:** Нет, Claude требует интернет. Presidio работает локально.

### Q: Какие языки поддерживает Claude?
**A:** Все языки, включая русский, казахский, английский. Но промпт оптимизирован для русского/казахского контекста.
