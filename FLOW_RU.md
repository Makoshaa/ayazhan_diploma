# Поток Работы Приложения - Полное Руководство

## Как Работает Приложение

### 1️⃣ Лендинг Страница (Первый визит)
- Пользователь открывает http://localhost:5173
- Видит лендинг страницу с кнопкой "Get Started"
- **Нажимает "Get Started"** → переходит на **страницу входа**

### 2️⃣ Регистрация
**Если у пользователя нет аккаунта:**
- На странице входа нажимает ссылку **"Sign up"**
- Заполняет форму регистрации:
  - Username (минимум 3 символа)
  - Email
  - Password (минимум 6 символов)
  - Подтверждение пароля
- Нажимает кнопку **"Sign Up"**
- Видит сообщение: "Registration successful! Redirecting to login..."
- **Автоматически перенаправляется на страницу входа через 2 секунды**

### 3️⃣ Вход в систему
**После регистрации или для существующих пользователей:**
- Вводит username и password
- Нажимает кнопку **"Sign In"**
- **Автоматически входит и перенаправляется на главную страницу приложения**

### 4️⃣ Главная Страница Приложения (После входа)
После входа пользователь видит:
- **Шапка** с:
  - Имя пользователя
  - Кнопка настроек
  - Кнопка "Home" (возврат на лендинг)
  - Кнопка "Logout" (выход)
- **Основное приложение** с функциями детекции PII:
  - Поле ввода текста
  - Выбор языка
  - Кнопка анализа
  - Панель результатов

### 5️⃣ Использование Приложения
- Вводит текст в поле ввода
- Выбирает язык (Английский/Русский)
- Нажимает **"Analyze"**
- Видит обнаруженные PII сущности
- Видит анонимизированный текст
- Может скопировать результаты

### 6️⃣ Выход из системы
- Нажимает кнопку **"Logout"** в шапке
- Токены удаляются из localStorage
- **Перенаправляется на страницу входа**

### 7️⃣ Повторный визит
**Когда пользователь открывает приложение снова:**
- Если токен валидный → **Автоматически входит на главную страницу**
- Если токен истек → **Перенаправляется на страницу входа**

## Важные Моменты

### ✅ ПРАВИЛЬНЫЙ ПОТОК:

1. **Лендинг** → Кнопка "Get Started" → **Страница входа**
2. **Страница входа** → Ссылка "Sign up" → **Регистрация**
3. **Регистрация** → Успешная регистрация → **Автоматический редирект на страницу входа (2 сек)**
4. **Страница входа** → Ввод данных → Кнопка "Sign In" → **Главная страница приложения**
5. **Главная страница** → Кнопка "Logout" → **Страница входа**
6. **Главная страница** → Кнопка "Home" → **Лендинг** (но остается залогиненным)

### 🔒 Защита маршрутов:

- **Лендинг страница**: Доступна всем (даже залогиненным)
- **Страницы входа/регистрации**: Доступны всем
- **Главная страница приложения**: ТОЛЬКО для залогиненных пользователей

### 💡 Ключевые изменения:

**ИСПРАВЛЕНО:**
- ✅ После регистрации → редирект на страницу входа (а не автоматический вход)
- ✅ После входа → автоматический переход на главную страницу приложения
- ✅ Лендинг всегда доступен через кнопку "Home"
- ✅ Кнопка "Get Started" на лендинге → страница входа (не сразу на приложение)

## Тестирование

### Тест 1: Новый пользователь
```
1. Открыть http://localhost:5173
   → Должен увидеть лендинг страницу

2. Нажать "Get Started"
   → Должен перейти на страницу входа

3. Нажать "Sign up"
   → Должен перейти на страницу регистрации

4. Заполнить форму и нажать "Sign Up"
   → Должен увидеть сообщение об успехе
   → Через 2 секунды перейти на страницу входа

5. Ввести username и password, нажать "Sign In"
   → Должен войти и увидеть главную страницу приложения
```

### Тест 2: Существующий пользователь
```
1. Открыть http://localhost:5173
   → Если токен валиден, сразу главная страница
   → Если токен истек, страница входа

2. Если на странице входа, ввести данные
   → Войти → главная страница
```

### Тест 3: Выход
```
1. На главной странице нажать "Logout"
   → Должен выйти и перейти на страницу входа
```

### Тест 4: Навигация
```
1. На главной странице нажать "Home"
   → Должен перейти на лендинг
   → Но остается залогиненным

2. На лендинге нажать "Get Started"
   → Должен сразу перейти на главную страницу
   → (потому что уже залогинен)
```

## Структура состояний

В App.tsx используется:
```typescript
const [currentView, setCurrentView] = useState<
  'landing' | 'login' | 'register' | 'app'
>('landing');
```

**Переходы:**
- `landing` → (Get Started) → `login`
- `login` → (Sign up) → `register`
- `register` → (Успех) → `login` (авто через 2 сек)
- `login` → (Вход успешен) → `app` (авто через isAuthenticated)
- `app` → (Home) → `landing`
- `app` → (Logout) → `login`
